# 전기기사 필기 준비 (cbt.chatgpts.kr)

전기기사 필기시험을 준비하는 수험생을 위한 무료 CBT형 기출문제 및 개념 복습 도구입니다.

- **도메인**: https://cbt.chatgpts.kr
- **저장소**: https://github.com/kuris/cbt.git
- **대상 과목 (5개 과목)**:
  1. 전기자기학
  2. 전력공학
  3. 전기기기
  4. 회로이론 및 제어공학
  5. 전기설비기술기준

## 주요 기능
- **비로그인 무료 풀이**: 누구나 5개 과목의 개념 요약, 기출문제, 오늘의 10문제, 랜덤 퀴즈, 150분 타이머 모의고사, 공식 암기 카드를 무료로 이용할 수 있습니다.
- **Google 로그인 연동**: 로그인 시 오답노트 영구 저장, 개인별 정답률 통계, 학습 이력을 클라우드에 자동 동기화합니다.
- **자체 작성 해설**: 모든 해설과 풀이 팁은 저작권 침해 없이 명확하고 신뢰할 수 있게 자체 작성되었습니다.
